# Guia do Cuprita

O Cuprita desenha esquemáticos e faz o layout de placas nos próprios arquivos do KiCad: abra o
projeto que você tem, ou comece um, e leve-o até a fábrica numa só janela. No app, F1 mostra estas
páginas e todos os comandos com suas teclas; Ctrl+K encontra qualquer comando, peça ou rede por
algumas letras.

## Páginas
- [Instalar](install.md): pacotes para Linux, compilar o código, a versão para navegador.
- [Sua primeira placa](first-board.md): de um projeto vazio aos arquivos que a fábrica aceita.
- [Esquemático](schematic.md): símbolos, fios, rótulos, folhas, barramentos, verificações, simulação.
- [Peças](parts.md): encontrar uma peça, trazer uma da web, fazer a sua.
- [Placa](board.md): posicionar, rotear, zonas, o contorno, camadas, verificações, 3D.
- [Fabricar](make.md): o que falta para o pedido, os arquivos de fabricação, pedir, montar à mão.
- [Análise](analysis.md): comprimento, corrente e impedância de uma rede, queda IR, alterações.
- [Perguntar e agentes](ai.md): perguntas respondidas neste computador; o Cuprita guiado por agentes.
- [Trabalhar com o KiCad](kicad.md): o que o Cuprita mantém, grava e deixa para o KiCad.

## Dez teclas para começar
| Tecla | Faz |
|---|---|
| Ctrl+K | Localiza ou executa qualquer coisa |
| F1 | Ajuda: todos os comandos e teclas |
| Ctrl+E | Alterna entre esquemático e placa (a peça selecionada continua selecionada) |
| A | Adiciona uma peça (um símbolo na folha, um footprint na placa) |
| W | Desenha um fio |
| F8 | Leva as peças e redes do esquemático para a placa |
| X | Roteia uma trilha |
| D | Verificações: o que falta rotear, problemas de regras de projeto |
| Ctrl+P | Grava os arquivos de fabricação |
| Ctrl+Z | Desfaz qualquer coisa |

As teclas são as do KiCad onde o KiCad tem uma, então funcionam igual nos dois.
